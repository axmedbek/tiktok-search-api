# Docs discipline

- `agent_docs/` is project memory — read before planning; update in `/dev` Phase 4 and `/end`.
- REPLACE stale sections, don't append (defer to `agent-docs-standards.md`).
- Every code change gets a `CHANGELOG.md` line.
- Don't document the obvious; document the non-obvious (why hit_shark, why RapidAPI over the vendored signer, why the two endpoints are merged).
- Keep `CLAUDE.md` + unconditional rules under ~10000 tokens total.
- Skills = HOW to do recurring domain tasks. Rules = MANDATORY constraints. agent_docs = current-state facts. Don't duplicate across the three.
